Claude Code隠しコマンド5つの使い方まとめ（リールで紹介した5つ）

リールで紹介した5つのコマンドの、使い方とコツをまとめました。
どれも Claude Code にはじめから入っているので、入れる作業はいりません。
黒い枠の文は、右の「コピー」を押して、そのまま貼り付けられます。

はじめに　Claude Code は、Claude の有料プラン（Pro 以上）で使えます。コマンドは、入力欄に「/」を打つと一覧が出てきます。続けて文字を打つと、しぼりこめます。

どこに打つの？（最初に読んでください）

A
Claude Code の入力欄に打つ
Mac の「ターミナル」で claude と入れて起動した画面の、いちばん下の入力欄に打って、Enter。
B
コマンドは文の先頭に
「/」で始まる言葉は、文の最初に置いたときだけコマンドとして動きます。

/btw（作業を止めずに、横から質問）

Claude が作業している途中でも、ちょっとした質問ができます。答えは横に出るだけで、今の会話の流れには足されません。

1
質問をつけて送る
/btw 今なにをしているか、ひと言で教えて
「/btw」のあとの文を、聞きたいことに書きかえて送ります。
2
前の答えをもう一度見る/btw だけを送ると、前にした横の質問と答えを見返せます。
!
向いている使い方「この言葉の意味は？」「あとどれくらいかかりそう？」など、本題とは別の小さな質問に。本題の指示は、ふつうに送ってください。

出どころ：Claude Code 公式ドキュメント（Commands・Interactive mode）

/voice（話しかけて指示を出す）

マイクに話した言葉が、入力欄に文字で入ります。キーボードで打つのと声を、まぜて使えます。

1
声の入力をオンにする
/voice
はじめてのときは、Mac に「マイクを使っていいか」と聞かれるので、許可します。
2
スペースキーを長押しして話す押しているあいだだけ録音されます。はなすと文字になって入るので、確かめてから Enter。
3
日本語で話すときは、先に言語を日本語にする何も設定していないと、英語として聞き取られます。入力欄に /config と入れて、言語（Language）を日本語にしておきます。
4
押しっぱなしが苦手なら
/voice tap
スペースを1回押すと録音が始まり、もう1回押すと送られます。やめるときは /voice off。
!
使えないときClaude.ai のアカウントでログインしているときだけ使えます（APIキーで使っている場合は使えません）。声は文字にするために Anthropic のサーバーに送られます。

出どころ：Claude Code 公式ドキュメント（Voice dictation）

/insights（自分の使い方を分析）

このパソコンでの最近の Claude Code の使い方を分析して、レポートを作ってくれます。よく作業している内容、つまずいたところ、次に試すといい機能まで出てきます。

1
そのまま送る
/insights
分析が終わると、ブラウザで見られるレポートができます。少し時間がかかります。
2
レポートの置き場所ホーム → .claude → usage-data → report.html前のレポートも日付つきで残ります（何もしなければ、30日たつと消えます）。
!
気をつけること分析にも、ふだんの使用量を使います。レポートには自分の作業の中身が書かれるので、人に見せる・SNSに載せるときは、見せたくないところを隠してください。

出どころ：Claude Code 公式ドキュメント（Manage costs・Analyze your usage patterns）

/usage（使った量と、残りが分かる）

今どれだけ使ったか、プランの上限まであとどれくらいかを、バーでひと目で見られます。

1
そのまま送る
/usage
Claude が作業している途中に送っても、止めずにすぐ表示されます。
2
何に使ったかも分かる有料プランなら、どのスキルやプラグインがどれくらい使ったかの内訳と、減らすためのおすすめも出ます。d と w のキーで「この24時間」と「この7日」を切り替えられます。
!
数字の見方このパソコンの記録から計算した目安です。スマホや claude.ai で使った分は入っていません。

出どころ：Claude Code 公式ドキュメント（Manage costs・/usage）

/context（AIの記憶の埋まり具合）

AI が一度に覚えておける量（コンテキスト）が、今どれだけ埋まっているかを、色つきのマスで見せてくれます。何が場所を食っているかと、空け方のおすすめも出ます。

1
そのまま送る
/context
色ごとに「会話」「道具の説明」「メモリ」などに分かれて表示されます。
2
くわしく見る
/context all
何がどれくらい使っているかを、全部ひらいて見られます。
3
いっぱいになってきたら別の作業に移るときは /clear（会話をまっさらにする）、同じ作業を続けるときは /compact（これまでの話を要約して場所を空ける）を使います。

出どころ：Claude Code 公式ドキュメント（Commands・Manage costs）

うまくいかないときは
① 「/」を打って一覧に出てくるか確かめる（出なければ Claude Code を新しくする）　② 出てきたエラーの文を、そのまま Claude Code に貼って「これを直したい」と送る 入力欄に /help と入れると、ほかのコマンドも見られます。
