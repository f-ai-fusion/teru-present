Claude Code神機能7つの入れ方まとめ（リールで紹介した7つ）

リールで紹介した7つの、入れ方と最初の使い方をまとめました。
黒い枠の文は、右の「コピー」を押して、そのまま貼り付けられます。
気になるものを1つ選んで、そこから試してみてください。

はじめに　Claude Code は、Claude の有料プラン（Pro 以上）で使えます。7つの道具そのものは無料で入れられます（⑤は、調べる場所を増やすときだけ追加の設定があります）。

どこに貼るの？（最初に読んでください）

A
「/」で始まる文 → Claude Code の入力欄
Mac の「ターミナル」で claude と入れて起動した画面に貼って、Enter。
B
それ以外の文 → ターミナル
Claude Code を起動する前の、ふつうのターミナルの画面に貼って、Enter。
C
入れたあとは、Claude Code を開き直す
入力欄に /exit と入れて閉じ、もう一度 claude で起動すると、新しい道具が使えるようになります。

frontend-design（Anthropic 公式のプラグイン）

ページや画面を作るときに、ありきたりな見た目にならないように、色・文字・配置を考えて作ってもらうための道具です。

1
Claude Code の入力欄に貼る
/plugin install frontend-design@claude-plugins-official
確認の画面が出たら、そのまま入れる方を選びます。
2
使い方「〇〇のページを作って」とふつうに頼むと、ページ作りのときに自動で使われます。

出どころ：github.com/anthropics/claude-plugins-official

Pixel Agents（働くAIがドット絵の事務所に出てくる）

Claude Code が作業しているあいだ、その様子をドット絵のキャラクターで見せてくれる道具です。

1
ターミナルに貼る
npx pixel-agents
Node.js（20以上）が必要です。入っていないと言われたら、nodejs.org から入れてください。
2
出てきたアドレスを開くターミナルに表示された「http://127.0.0.1:…」のアドレスを、ブラウザで開きます。別の画面で Claude Code を動かすと、キャラクターが現れます。
3
VS Code を使っている人はVS Code の拡張機能で「Pixel Agents」を探して入れる方法もあります（VS Code 1.105.0 以上）。

出どころ：github.com/pixel-agents-hq/pixel-agents

3Dコネクター（Blender）（言葉で3Dを作る）

無料の3Dソフト「Blender」と Claude をつないで、言葉で頼んだものを Blender の中に作ってもらうための、公式のコネクターです。手順が少し多いので、最後に回してもOKです。

1
Blender を入れるblender.org から無料で入れられます（5.1 以上が必要）。
2
Claude のアプリでコネクターを入れるClaude（デスクトップアプリ） → 設定 → コネクタ →「blender」で探す →「インストール」
3
Blender 側の部品を入れるblender.org/lab/mcp-server のページにある入れるためのリンクを、Blender の画面にドラッグします。2回ドラッグします（1回目で置き場所が足され、2回目で入ります）。
4
動いているか確かめるBlender → Edit → Preferences → Add-ons →「MCP」→「Server is running」と出ていればOKあとは Claude に「Blenderで〇〇を作って」と頼みます。
5
Claude Code でも使うとき（Mac・ターミナルに貼る）
claude mcp add blender -- "$HOME/Library/Application Support/Claude/Claude Extensions/ant.dir.gh.blender.blender-mcp/.venv/bin/blender-mcp"
2 で入れたコネクターを、Claude Code からも使えるようにする文です。
!
気をつけることBlender の公式ページに「AIが作った命令を、確認なしで Blender の中で動かす」と注意が書かれています。大事な作品のファイルでは使わず、試し用のファイルで使ってください。

出どころ：blender.org/lab/mcp-server ・ Claude のコネクタ一覧（Anthropic & Partners）

claude-mem（前の話を覚えておく）

Claude Code でやったことを記録しておき、次に開いたときに前の作業の続きを思い出せるようにする道具です。

1
Claude Code の入力欄に、1行ずつ貼る
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
2
ターミナルから入れる方法もあります
npx claude-mem install
Node.js（20.19 以上、または 22.12 以上）が必要です。「npm install -g claude-mem」では入らないので注意。

出どころ：github.com/thedotmack/claude-mem

last30days（この30日の話題を調べる）

調べたい言葉について、ここ30日のあいだにネットで話題になった投稿を集めて、出どころつきでまとめてくれる道具です。

1
Claude Code の入力欄に、1行ずつ貼る
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
2
使い方
/last30days 調べたいこと
「調べたいこと」を書きかえて送ります。最初の1回は、設定の案内が出ます。
3
そのままで調べられる場所設定なしで Reddit・Hacker News・GitHub などが使えます。X・YouTube・Instagram などを足すには、それぞれ追加の設定が要ります（有料のキーが要るものもあるので、使う前に案内をよく読んでください）。

出どころ：github.com/mvanhorn/last30days-skill

oh-my-claudecode（AIのチームで動かす）

役割のちがう何人ものAIに仕事を分けて、同時に進めてもらうための道具です。

1
Claude Code の入力欄に、1行ずつ貼る
/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode
/plugin install oh-my-claudecode
2
最初の設定をする
/omc-setup
質問が出たら、答えながら進めます。

出どころ：github.com/Yeachan-Heo/oh-my-claudecode

/rewind（さっきの状態に戻す）

Claude Code にはじめから入っている機能です。入れる作業はいりません。

1
入力欄が空のときに Esc を2回または、入力欄に /rewind と入れて Enter。これまでに送った文の一覧が出ます。
2
戻したいところを選ぶ「コードと会話を戻す」「会話だけ戻す」「コードだけ戻す」などから選べます。
3
戻らないものもありますターミナルの命令で変わったファイルや、Claude Code の外で手で直したファイルは、戻らないことがあります。大事なファイルは、別に保存しておくと安心です。

出どころ：Claude Code 公式ドキュメント（Checkpointing）
